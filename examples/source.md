# Example source

## Problem

Teams often start content production with a title but no evidence map. The
writer then repeats the same promise under different headlines.

## Workflow

A useful content workflow separates source indexing, topic planning, writing,
image generation, delivery, and audit. Every external mutation should have a
review gate and a resumable state file.

## Acceptance

An operational workflow reports counts from artifacts, not from a single
process exit. It must preserve identifiers before verification so retries do
not create duplicate records.
